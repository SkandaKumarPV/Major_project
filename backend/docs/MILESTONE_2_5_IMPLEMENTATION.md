# Milestone 2.5 — Adaptive Three-Question Technical Interview

## Scope

This implementation adds Stage 2 for the initial `Generative AI Engineer` role.

It preserves the existing LiveKit Agents, Deepgram STT, configurable LLM provider, Cartesia TTS, manual turn detection and 10-second silence handling.

It does not implement final resume or interview scoring.

## Backend workflow

1. Stage 1 remains responsible for introduction and up to two resume/project cross-questions.
2. On the Stage 1 transition, the runtime initializes Stage 2 and selects one unused Easy main question from `role_question_bank.db`.
3. Each candidate technical answer is evaluated in one structured LLM turn. The response contains an answer assessment, turn type, optional contextual follow-up, completion decision, optional next-difficulty recommendation and candidate-facing speech.
4. Follow-ups are generated by the LLM and are never queried from or inserted into the question bank.
5. The backend validates the response, enforces a maximum of two follow-ups, validates the next difficulty, selects the next unused main question from the database, and persists Stage 2 state in `structured_memory`.
6. The LiveKit transcript recorder continues to persist final candidate transcripts and committed interviewer speech.

## State

`technical_interview` in `InterviewSessionRecord.structured_memory` stores selected main question records and IDs, completed question IDs, current question, current difficulty, next difficulty, follow-up count, compact assessments and completion status.

The existing session columns are also updated for current question ID, used IDs, completed IDs, follow-up count and current stage.

## Hard limits

- Exactly three main questions for a completed Stage 2.
- Main Question 1 is Easy.
- Main Questions 2 and 3 use a validated difficulty recommendation or a conservative backend fallback.
- No repeated main question IDs.
- At most two follow-ups per main question.
- The LLM cannot select or invent main questions or modify backend state.
- Greetings and candidate questions are conversational turns and do not advance question counters when classified as such by the structured turn response.
